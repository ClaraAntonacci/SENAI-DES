# Pedra, Papel, Tesoura, Lagarto e Spock

##  Descrição do Projeto

Este projeto é uma versão web do clássico jogo **Pedra, Papel e Tesoura**, inspirado na versão apresentada por Sheldon Cooper na série The big bang theory

O jogo permite que o usuário escolha entre cinco opções:

- 🪨 Pedra
- 📄 Papel
- ✂️ Tesoura
- 🦎 Lagarto
- 🖖 Spock

O sistema realiza escolhas aleatórias para o computador, calcula automaticamente o vencedor da rodada e mantém a pontuação do jogador.

---

# Funcionalidades

- Escolha entre 5 opções
- Sistema de pontuação
- Escolha aleatória do computador
- Tela de regras
- Animações e efeitos visuais
- Interface interativa e responsiva

---

#  Tecnologias Utilizadas

- HTML5
- CSS
- JavaScript

---

#  Regras do Jogo

- ✂️ Tesoura corta Papel
- 📄 Papel cobre Pedra
- 🪨 Pedra quebra Tesoura
- 🪨 Pedra esmaga Lagarto
- 🦎 Lagarto envenena Spock
- 🖖 Spock quebra Tesoura
- ✂️ Tesoura decapita Lagarto
- 🦎 Lagarto come Papel
- 📄 Papel refuta Spock
- 🖖 Spock vaporiza Pedra
